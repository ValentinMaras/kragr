# Glossar Statiq DE → FR / ES (verbindlich, Eurocode-Begriffe der NF EN / UNE-EN)

Allgemein
- Nachweis → vérification / comprobación · erfüllt / nicht erfüllt → vérifié / non vérifié · cumple / no cumple
- Bemessung → dimensionnement / dimensionamiento · Rechenweg → étapes de calcul / desarrollo del cálculo
- Bericht → rapport / informe · Eingaben → données / datos · Ergebnis → résultat / resultado
- Abhilfe („So wird der Nachweis erfüllt“) → Comment satisfaire la vérification / Cómo cumplir la comprobación
- GZT (ULS) → ELU / ELU · GZG (SLS) → ELS / ELS · Teilsicherheitsbeiwert → coefficient partiel / coeficiente parcial
- Einwirkung → action / acción · Bemessungswert → valeur de calcul / valor de cálculo · charakteristisch → caractéristique / característico
- NA (Nationaler Anhang) → AN (Annexe nationale) / AN (Anejo Nacional); Normbezeichnungen wie „DIN EN 1992-1-1/NA“ bleiben unverändert
- erf. / vorh. / zul. → req. / exist. / adm. (FR: requis / existant / admissible; ES: nec. / exist. / adm.)
- Beispiel → exemple / ejemplo · Fall → cas / caso · Tabelle → tableau / tabla · Abbildung/Skizze → figure / figura

Baustatik / Lasten
- Einfeldträger → poutre sur deux appuis / viga biapoyada · Durchlaufträger → poutre continue / viga continua · Kragarm → console / voladizo
- Auflager → appui / apoyo · Festlager → appui fixe / apoyo fijo · Loslager → appui mobile (appui simple) / apoyo móvil · Einspannung → encastrement / empotramiento · Gelenk → articulation / articulación (rótula)
- Schnittgrößen → efforts internes / esfuerzos internos · Moment → moment (fléchissant) / momento (flector) · Querkraft → effort tranchant / esfuerzo cortante · Normalkraft → effort normal / esfuerzo axil
- Fachwerk → treillis / celosía · Rahmen → portique / pórtico · Stab → barre / barra · Knoten → nœud / nudo · Einflusslinie → ligne d'influence / línea de influencia
- Eigengewicht → poids propre / peso propio · Nutzlast → charge d'exploitation / sobrecarga de uso · Schnee → neige / nieve · Wind → vent / viento · Lastannahmen → actions sur les structures / acciones en la edificación

Stahlbeton
- Stahlbeton → béton armé / hormigón armado · Bewehrung → armatures / armadura · Bügel → cadres (étriers) / cercos (estribos) — einheitlich „étriers“ / „estribos“
- Betondeckung → enrobage / recubrimiento · Verlegemaß → enrobage nominal / recubrimiento nominal · Expositionsklasse → classe d'exposition / clase de exposición
- guter / mäßiger Verbund → bonnes / mauvaises conditions d'adhérence · buenas / malas condiciones de adherencia
- Verankerungslänge → longueur d'ancrage / longitud de anclaje · Übergreifungsstoß → recouvrement / solape
- Druckstrebe → bielle (de compression) / biela (de compresión) · Durchstanzen → poinçonnement / punzonamiento · Plattenbalken → poutre en T / viga en T
- Stütze → poteau / pilar · Platte → dalle / losa · Balken → poutre / viga · Wand → voile (mur) / muro · Riss → fissure / fisura · Kriechen → fluage / fluencia · Schwinden → retrait / retracción

Stahlbau
- Knicken → flambement / pandeo · Biegedrillknicken (Kippen) → déversement / pandeo lateral · Beulen → voilement / abolladura
- Querschnittsklasse → classe de section / clase de sección · Profil → profilé / perfil · Steg / Flansch → âme / semelle · alma / ala
- Schraube → boulon / tornillo · Scherfuge → plan de cisaillement / plano de corte · Lochleibung → pression diamétrale / aplastamiento
- Schweißnaht → soudure / soldadura · Kehlnaht → soudure d'angle / soldadura en ángulo · Stumpfnaht → soudure bout à bout / soldadura a tope
- Stirnplatte → platine d'about / chapa frontal · Stützenfuß → pied de poteau / basa de pilar · Knicklinie → courbe de flambement / curva de pandeo

Holzbau
- Vollholz → bois massif / madera maciza · BSH → bois lamellé-collé (BLC) / madera laminada encolada (MLE) · KVH bleibt KVH
- Nutzungsklasse (NKL) → classe de service (CS) / clase de servicio (CS) · KLED → classe de durée de chargement / clase de duración de la carga
- ständig / lang / mittel / kurz / sehr kurz → permanente / long terme / moyen terme / court terme / instantanée · permanente / larga duración / media duración / corta duración / instantánea
- Abbrand → carbonisation / carbonización · Verbindungsmittel → organe d'assemblage / medio de unión · Querzug → traction perpendiculaire / tracción perpendicular · Durchbruch → percement / perforación (agujero)

Mauerwerk
- Mauerwerk → maçonnerie / fábrica · Stein → élément (brique, bloc) / pieza · Mörtel → mortier / mortero · Lagerfuge / Stoßfuge → joint horizontal / joint vertical · tendel / llaga · Überbindemaß → recouvrement / solape · Dünnformat (DF) bleibt als Eigenname

Grundbau
- Grundbruch → rupture par défaut de capacité portante / hundimiento · Gleiten → glissement / deslizamiento · Kippen → renversement / vuelco
- Setzung → tassement / asiento · Erddruck aktiv/passiv → poussée / butée · empuje activo / pasivo · Erdruhedruck → pression des terres au repos / empuje en reposo
- Fundament (Einzel-/Streifen-) → semelle (isolée / filante) / zapata (aislada / corrida) · Sohle → base de la fondation / base de la zapata · Sohlwiderstand → résistance du sol / resistencia del terreno
- Böschung → talus / talud · Spundwand → rideau de palplanches / tablestacado · Pfahl → pieu / pilote · Grundwasser → nappe (eau souterraine) / agua subterránea (nivel freático) · bindig / nichtbindig → cohérent / pulvérulent · cohesivo / granular

Wasserbau
- Gerinne → canal / canal · schießend / strömend → torrentiel / fluvial · supercrítico / subcrítico · Wechselsprung → ressaut hydraulique / resalto hidráulico
- Druckstoß → coup de bélier / golpe de ariete · Rohrleitung → conduite / tubería · Brunnen → puits / pozo · Pumpe → pompe / bomba · Auftrieb → poussée d'Archimède / empuje (flotación)

Bauphysik
- Wärmeschutz → protection thermique / protección térmica · U-Wert → coefficient U / transmitancia U · Wärmeleitfähigkeit λ → conductivité thermique / conductividad térmica
- Tauwasser → condensation / condensación · Schimmel → moisissure / moho · Schallschutz → isolation acoustique / aislamiento acústico · Flankenübertragung → transmission latérale / transmisión por flancos
- Brandschutz → sécurité incendie / protección contra incendios · Gebäudeklasse (GK) → classe de bâtiment GK / clase de edificio GK (Kürzel GK beibehalten, deutsche MBO) · Nutzungseinheit → unité d'usage / unidad de uso · feuerhemmend / hochfeuerhemmend / feuerbeständig → coupe-feu 30 / 60 / 90 min (FR: « résistant au feu 30 min » usw.) · resistente al fuego 30 / 60 / 90 min

Form
- Zahlen: Dezimalkomma wie im Deutschen beibehalten (FR und ES schreiben ebenfalls 0,5). Einheiten, Formelzeichen, Indizes, Normverweise und Abschnittsnummern unverändert.
- FR: typografisch « » sind nicht nötig; normale Leerzeichen genügen. ES: ¿…? und ¡…! korrekt setzen.
- Ton: knapp, sachlich, für Studierende verständlich; Anrede höflich und einheitlich: FR „vous“, ES „usted“. „Bitte … eingeben“ → FR « Veuillez saisir … » / ES « Introduzca … ». Knopf- und Menübeschriftungen im Infinitiv bzw. als Substantiv (FR « Calculer », ES « Calcular »).
