Simply Supported Beam — Theory

System

A simply supported beam rests on a pin at A and a roller at B. It is statically determinate — 3 equilibrium equations are sufficient.

Reactions

ΣF_y = 0 → A + B = ΣFᵢ·cos(αᵢ) + ΣqᵢLᵢ
ΣM_A = 0 → B·L = ΣFᵢ·cos(αᵢ)·aᵢ + Σqᵢ·Lᵢ·x̄ᵢ

Shear Force Q(x)

Q(x) = A − ΣFᵢ·cos(αᵢ)·H(x−aᵢ) − Σqᵢ·⟨x−aᵢ⟩
H = Heaviside, ⟨·⟩ = Macaulay bracket

Bending Moment M(x)

M(x) = A·x − ΣFᵢ·cos(αᵢ)·⟨x−aᵢ⟩ − Σqᵢ·⟨x−aᵢ⟩²/2
Tension-bottom: positive M shown downward

Inclined Loads

F_y = F·cos(α)  → Q, M
F_x = F·sin(α)  → N (normal force)
Cantilever — Theory

System

A cantilever is fully fixed at A (moment, shear, normal) and free at the other end. It is statically determinate.

Reactions at A

V_A = ΣFᵢ·cos(αᵢ) + ΣqᵢLᵢ
H_A = ΣFᵢ·sin(αᵢ)
M_A = ΣFᵢ·cos(αᵢ)·aᵢ + Σqᵢ·Lᵢ·x̄ᵢ

Shear Force & Moment

Q(x) = V_A − ΣFᵢ·cos(αᵢ)·H(x−aᵢ) − Σqᵢ·⟨x−aᵢ⟩
M(x) = −M_A + V_A·x − ΣFᵢ·cos(αᵢ)·⟨x−aᵢ⟩ − Σqᵢ·⟨x−aᵢ⟩²/2
Continuous Beam — Theory

Static Indeterminacy

A continuous beam with n spans has (n−1) intermediate supports. Each extra support introduces one additional unknown reaction, making the system statically indeterminate to the (n−1)th degree. Equilibrium alone is not sufficient — compatibility of deformations must also be satisfied.

Three-Moment Equation (Clapeyron)

For each intermediate support i, the compatibility condition relates the moments at supports i−1, i, and i+1:

Mᵢ₋₁·Lᵢ + 2Mᵢ·(Lᵢ+Lᵢ₊₁) + Mᵢ₊₁·Lᵢ₊₁ = −6·(Aᵢ·āᵢ/Lᵢ + Aᵢ₊₁·b̄ᵢ₊₁/Lᵢ₊₁)
Lᵢ = span length i, Aᵢ = area of M₀ diagram in span i
āᵢ = distance of centroid from left support

Solution Method

The three-moment equation is the classic hand method. calc itself uses the displacement method in matrix form (as for frames), so end fixity, cantilevers, hinges, different stiffnesses per span and point moments can be combined freely. M, Q and the deflection follow exactly from the nodal displacements.

Options: fixed ends, cantilevers, hinges

Counting rule for beams (vertical loads): n = a − 2 − g, with a = vertical support reactions plus clamping moments (fixed end 2, pin/roller 1) and g = number of hinges. n = 0: statically determinate (e.g. Gerber beam), n < 0: mechanism. In a hinge the moment is zero. Ii/I scales the stiffness of a span — in indeterminate systems this shifts the support moments towards the stiffer span.

Boundary Conditions

Superposition

Within each span, Q(x) and M(x) are found by treating the span as a simply supported beam with the computed end moments applied as external moments, superimposed with the applied loads.
